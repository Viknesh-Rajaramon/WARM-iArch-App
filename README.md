# Flutter Air Quality Sample

This is a simple Flutter sample project that demonstrates:

- Networking with the `http` package
- State management with `Provider`
- A clean UI for displaying indoor air quality sensor data (PM2.5 and CO2)

## Running the App

1. Install Flutter (>=3.0).
2. Clone this repo or copy the files into a Flutter project.
3. Run:

```bash
flutter pub get
flutter run
